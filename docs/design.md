# Delivery and ownership contracts

A returned event ID proves durable broker acceptance, not application receipt. Internal adapter ACK and application-level receipt differ. Canonical relay names, stable UUID identities, binding epochs, queue ownership and compare-before-write fencing remain unchanged. Read-only inspection never advances a receive cursor.

Source code, installed code and runtime state have separate owners. A public repository rename is not a DB/session/root migration. A manifest hash does not prove a running process loaded the new code; activation is independently selected and observed. Autostart and local channel policy are not consequences of copying code.

Installation replaces only immutable, explicit owned files after prior-hash verification. Same-name foreign integrations and edited immutable files refuse. Unknown neighbors and private state are preserved. Retirement requires previous ownership, an explicit old hash in the new retirement declaration and unchanged bytes. Recognizable same-user legacy broker/schema anchors permit automatic adoption only through known-hash file checks and private recovery copies; there is no public consent override of that admission. A partial failure never authorizes stale DB restoration.

Harness additions expand a retained selection union; omitted selectors never uninstall. Fresh selection discovers only locally available supported executables and permits service-only when none exist. Claude parent junctions may resolve only to their corresponding same-user canonical directories. OMP's public config path supplies the actual selected agent directory; no profile-layout derivation is used. Bound interpreter/state/root/port inputs and existing registration shape are preserved. Config changes use supported public typed APIs in isolated WorkRoot copies and preserve unrelated contributions. Verify is read-only/no-network and refuses missing/changed closure rather than repairing it.
